## Context（なぜやるか）

内容は 1,757語・183レッスン・骨学試験339項目まで増えたが、使い方の面は前回の「使いやすさの見直し」（取り消し・離れるときの確認・数字キーなど）から整理していない。調べて分かった主な困りごと:

- **iPad の縦向き（幅 820〜834px）がスマホ扱い**になり、3Dが上 46% に固定される（styles.css:112 の境目が 900px）。3Dと説明の割合も変えられない。
- **ホームが長い一覧**: 骨格系40・循環器29・筋28レッスンを1列に並べ、骨格は足した順（頭蓋の部位が9レッスンに散らばり「（追加）」も多い）。ホームに検索が無く、「次のレッスン」は内容の最初から数えるので、筋系を学んでいても基本の用語を勧め続ける。
- **学習の流れが長く、やめにくい**: 31語のレッスンは「次へ」31回＋確認テスト約62タップ。途中でやめると何も残らない（lesson.ts:61 で最後にまとめて保存。再読み込みには確認も無い）。正解でも毎回全文の語カード＋「次へ」。復習には区切りも「やめる」も無く、「残り N」は増えたり減ったりする。
- **まちがいから戻れない**: 骨学試験のまちがえた項目は文字だけ（ui/exam.ts:167）、復習の語根・試験はそれぞれの一覧へしか飛ばない（review.ts:74-75）、進捗の苦手な語は図鑑を開かない。試験の項目は一覧から選べない。
- **最初の読み込みが重い**: ホームが全系統の GLB 約25MB を読み込み（home.ts:13）、3Dの準備ができるまで説明欄は空のまま（main.ts:48）。
- 設定は進捗の画面の下に2つだけ。はじめての人への案内・3Dの操作の説明が無い。押す所が小さいものがある（チップ 34px、タブ 約36px）。

方針（利用者の答え）: **iPad と PC が中心で、iPhone は一部**。**毎日の学習と骨学試験の対策を同じくらい**重く見る。骨格系は**部位ごとに並べ直し、「（追加）」の表記もなくす**。

いつもの進め方にそろえ、6つに分けて1つずつ公開する（2026-11-01 にその1〜その6 を公開。各段の実際は docs/設計.md の「段階」）。始めるとき、この計画を docs/使いやすさ.md に写し、終えたものは docs/設計.md の「段階」と「公開とスマホ」に書く。

## その1 画面の配置と読み込み（iPad・PC の土台）

1. **iPad の縦向きも3Dと説明を左右に並べる**: styles.css:112 の境目を `min-width: 900px` から `min-width: 768px` にする（横向きのスマホの条件はそのまま）。説明欄の幅は `min(440px, 50%)` から `clamp(340px, 42%, 480px)` にする。
2. **境目のつまみ**: 3Dと説明の境目をドラッグして幅を変えられるようにし、db.settings に残す（新しく `src/ui/splitter.ts`）。縦に並ぶ iPhone では、3Dの高さを3段（小 34%・中 46%・大 62%）から選ぶ。3Dの右上に「3Dを大きく」（説明欄を一時的にたたむ）を置き、変えたあとは viewer の大きさを更新する（viewer.ts の resize。ResizeObserver で）。
3. **押す所の大きさ**: `@media (pointer: coarse)` でチップ・タブ・「視点を戻す」・×ボタンを 44px 以上にする（styles.css:40, 66, 134, 178, 276）。3Dの上のツールが横にすべる iPhone では、端をぼかして続きがあることを見せる。左上の案内文と「視点を戻す」が重ならないよう、案内文に max-width を付ける。
4. **ホームで全部読み込まない**: ホームの3Dは皮膚と骨格系だけにし（home.ts:13）、ほかの系統は使う画面で読み込む。そのため start() で `viewer.ready` を待つ前に説明欄を描き、3Dが要る所だけ待つ（main.ts:47-58）。
5. **読み込みの進み具合**: viewer.ts の GLB 読み込み（985-1016行）で fetch の進み具合を取り、「筋系を読み込み中 3.2 / 7.1MB」と出す。失敗したことを示す印は、あとから別の系統の読み込みが終わっても消えないようにする。
6. **iPad のキーボード・トラックパッド**: 数字のキーを一度押したら選択肢に番号を出す（今は `hover: hover` の端末だけ。styles.css:216）。

## その2 ホームの整理（探す・続ける）

1. **レッスンのまとまり（group）**: content/terms/*.json の各レッスンに `group` を付ける（スキーマは src/content.ts:79、確かめるのは scripts/validate-content.mjs）。ホームは「系統 → まとまり → レッスン」の入れ子のフォルダーにする。今の folder()（home.ts:25-40）を入れ子でも使えるようにし、開いたフォルダーを覚える仕組みもそのまま使う。図鑑の一覧（explore.ts:303-313）も同じ入れ子にする。
2. **骨格系を部位ごとに並べ直す**: まとまりの名前は骨学試験の区分（総論・体幹・上肢・下肢・頭蓋）にそろえ、試験と演習の絞り込みと同じ言葉にする。
   - 混ざっているレッスンは語を分ける: 中手骨と中足骨、指節骨と楔状骨、肋骨と上肢の骨の部位、体幹と四肢の部位、頚椎・腰椎・胸郭と上肢、骨格のまとまり。
   - まとまりの中は「骨の名前 → 部位 → 細かい部位」の順に並べる。大きすぎる「頭蓋の部位」（31語）と「頭蓋の縫合の交点…」（22語）は分ける。
   - 題から「（追加）」をなくし、何のレッスンか分かる名前にする（例:「頭蓋：外面と顔面」「頭蓋：頭蓋底の孔と裂」）。
   - 学んだ記録は語ID で残る（db.learned の termId）ので消えない。並べ直しは一度だけ動かすスクリプトで行い（scratchpad に置く）、474語がどれも1回ずつ残っているかを確かめる。
   - レッスンID が要る所: quiz.ts:63（選択肢はまず同じレッスンから取る。部位でまとめると紛らわしい選択肢が良くなる）、context.ts:50 の sceneFor、build-models.mjs:216（神経だけ）。
3. **ほかの大きい系統にも group を付ける**: 循環器（心臓・頭頚部・上肢・体幹・下肢・静脈）、筋（同じ部位の分け方）、神経（中枢・脳神経・上肢・下肢）、関節・局所解剖。語は動かさず、group を付けて並べ直すだけ。
4. **続きから**: nextLesson()（home.ts:87）を「最後に学んだレッスン（db.learned の learnedAt が一番新しいもの）の次の、まだ終えていないレッスン。同じまとまりを優先」に変える。ホームの上に「最近のレッスン」を3つ出し、途中までのレッスンには「続き」の印を付ける。
5. **ホームの検索**: 「今日の復習」の下に検索欄を置き、レッスンの題と語（日本語・読み・英語・ラテン語）を探す。図鑑の表記ゆれの処理（explore.ts:403 あたりの normalize）を src/ に移して両方から使う。レッスンを選ぶと #/learn、語を選ぶと #/explore/<ID> へ移る。

## その3 学習の流れ（短く・やめやすく）

1. **レッスンを途中でやめても残る**: 確認テストで答えた語から1つずつ db.learned に入れる（骨学試験 ui/exam.ts:102 と同じ考え方）。開き直すと、まだ答えていない語から続ける。今の「最後にまとめて保存」（lesson.ts:60-62）と、それに合わせた guard の文（context.ts:19）を直す。
2. **確認テストへ飛ぶ**: 語を見る画面の上に「確認テストへ」をいつも出す（知っている語を31回めくらずに済む）。レッスンの数え方「i / n」が3Dの案内と見出しの2か所に出ているので（lesson.ts:41, 46）1つにする。
3. **終わりの画面のボタンをそろえる**: どの画面も「ホームへ」と主な次の一手1つにする。
   - レッスン → 次のレッスン（今は無い）
   - 復習 → 次のレッスン
   - 演習 → 同じ条件でもう一度（今は設定の画面に戻ってしまう。古い覚え具合を使う drill.ts:29-32 の不具合も直す）
   - 骨学試験 → 続ける
4. **復習の区切り**: 復習を始めるとき「10問・20問・全部」を選ぶ（前回選んだものを残す）。答えた数の帯（解いた数 / 区切り）を出す。「ここでやめる」でそこまでのまとめを出す。「間違えた問題は10分後」の文を、新しい語なら1分後とする正しい文に直す（review.ts:69）。
5. **正解のときは短く**: 正解なら語カードを短い形にし（term-card.ts の compact を使う）、「くわしく」で全文を開く。設定で「正解したら自動で次へ（1.5秒）」を選べるようにする。不正解・惜しいときは今と同じく全文を出す。
6. **PC・iPad のキーボード**: 答えたあとは、ボタンにフォーカスが無くても Enter・→ で次へ進む。ほかのキーは次のとおり。
   - Backspace: 押しまちがいの取り消し
   - 名前→位置の問題の 0: わからない（今はキーで答えられない）
   - Esc: やめる
   - ?: キーの一覧
   - /: 検索欄へ

   onKeys（src/dom.ts:31）に足す。英語の入力欄にも、骨学試験と同じく変換中の Enter を無視する処理を入れる（ui/exam.ts:278 と同じ形）。
7. **演習**: 押しても消せない最後のチップには理由を出す。「苦手な順」で解いたものがまだ無いときは、そのことを文で出す。系統を選ぶ所で、その2 の「まとまり」でも絞れるようにする（骨格の「頭蓋」だけ、など）。

## その4 つながり（まちがいから戻る・試験の項目を選ぶ）

1. **まちがいから、その項目へ**: 次の4つを、どれもその項目そのものへ飛ぶようにする。
   - 骨学試験のまちがえた項目（ui/exam.ts:167）
   - 復習のまちがえた語根・試験の項目（review.ts:74-75）
   - 語カードの「試験 N回」（term-card.ts:123）: その語の出る項目に絞った一覧へ
   - 進捗の苦手な語（progress.ts:73）: 図鑑へ

   語根は #/roots?root=<ID> でそのカードを開いて出す。試験の項目は下の2の一覧から開く。
2. **骨学試験の項目の一覧**: #/exam/<区分> に「項目を見る」を足す。区分の絞り込み（総論〜頭蓋）・覚え具合・出た回数を並べ、押すとその1問から解く（新しい形 `#/exam/<区分>/<ID>`）。
3. **図鑑**: 語を選んだらアドレスを #/explore/<ID> に変え、戻るボタンで前に見た語に戻れるようにする（main.ts で、図鑑の中の移動では画面を作り直さない）。検索欄は説明欄の上に留める（今は語カードの下。explore.ts:394）。検索結果には系統と親の語を添え、消す×を付ける。3Dの右上に「全身を見る」を置く。
4. **断面**: オンにしても、今見ている系統だけで切る（今は関節・リンパ以外の全系統を読み込む。explore.ts:103）。ほかの系統を足すのはボタンで。

2. **試験日**: 設定で骨学試験の日を入れると、ホームの上に「試験まで N日・まだの項目 M → 1日 K項目」を出し、その日の分へすぐ飛べるボタンを置く。examProgress（src/exam.ts）を使って数える。

6. **読み上げ**: 正誤の帯に `role="status"` を付け、今のタブに `aria-current` を付ける。

## その7 学び方を選ぶ・復習を使いやすく（2026-11-02）

利用者の声: 学習で「場所から覚えるか、日本語→英語・英語→日本語から覚えるか」を自分で選びたい。復習は今のままでは使いづらい（何が出るか分からない、範囲を絞れない、まちがえた問題がその回の中で出ないことがある、正解でも当てずっぽうだったときに伝えられない）。

1. **レッスンの始めの画面**（ui/lesson.ts の startScreen）: どのレッスンも始めに1枚の画面を出し、初めの説明（intro）・語の一覧・「確認テストで覚えること」を選ぶ。
   - まとめて選ぶ「場所から・日本語→英語・英語→日本語・ぜんぶ」と、1つずつのチップ（位置→名前・名前→位置・日→英・英→日）がある。
   - 選んだものは preferences.lessonFacets に覚える（初めは位置→名前と名前→位置で、今までと同じ）。
   - 確認テストは、選んだ問い方を語ごとに順に回す（study.ts の lessonFacet。その語に出せない問い方は飛ばす）。
   - 途中のレッスンでは同じ画面に「続きから」「はじめから」を出す。
2. **学ぶ問い方**（設定。preferences.studyFacets、初めはすべて）: 語の問い方を足し外しできる。基本の4つのどれか1つは残す。
   - 外した問い方は新しく始めず、期限が来ても復習に出さない（記録は残る）。
   - 筋の3つと通るものは、位置→名前を学ぶならそれが、学ばないなら選んだ基本の問い方のどれかが復習の段階に入ってから出す（study.ts の unlockedTerms）。
   - 演習は、初めにこの設定の問い方を選んだ状態で開く（外したものも選べる）。演習の問い方の一覧は study.ts の TERM_KINDS にまとめた。
3. **復習の始めの画面**（ui/review.ts の chooseReview）: 問題があればいつも出し、次のことができる。
   - 今日の数を「復習 X・新しい Y」に分けて見る。
   - 範囲（系統ごと・語根カード・骨学試験）のチップで絞る。チップにはそれぞれの数を出す。
   - 「問い方・新しい問題で絞る」を開くと、問い方と「新しい問題を出す／復習だけ」でも絞れる。
   - 1回に解く数を選んで始める。
   - 絞るのは今日の問題（新しい問題の上限は絞る前に数える）の中からなので、ホームの数と食いちがわない。範囲と問い方は毎回すべてから始め、1回に解く数だけを覚える。
4. **まちがえた問題をその回の終わりに**: 期限の来た問題が無くなったら、この回でまちがえてまだ正解していない問題（Setup.pending）を、20分先までなら期限を待たずに「もう一度」として出す（buildQueue の aheadUntil）。
   - 一度正解したものは、前倒しでは出さない（10分後の期限にふつうに出る）。
   - 「ここでやめる」のあとの「続ける」は、同じ範囲・数・まちがえた問題を引きついで続きから解く。
5. **自信なし**: 正解の答え合わせの画面に「自信がなかった（早めにもう一度出す）」（キーは H）を出す。押すと判定を Hard に付け直す（fsrs.ts の recordReview が返す regrade。最後の記録を取り消してから書くので、何度押しても解いた記録は1回分）。もう一度押すと元の判定に戻る。語・語根・骨学試験で共通（quiz.ts の waitResult）。
6. **終わりの画面**: まちがえた語に、まちがえた問い方を添える。ほかの範囲に今日の問題が残っていれば「ほかの範囲を復習する（N問）」を出す。
   - 今日の問題が無いときは、次の復習がいつか（24時間のうちに何問か）と、新しい問題の1日の上限に届いたことを出す。

確かめたこと: `npm run check`。開発サーバーを Playwright（PC 1180×820 と iPhone 390×844）で動かして次を見た。
- レッスンで「日本語→英語」を選ぶと確認テストが日→英だけになる。
- 「自信なし」で次の出題が10分後から6分後になる。
- 復習の始めの画面で「名前→位置」を外すと 20問→13問になる。
- まちがえた2問をはさんで Esc で「ここでやめる」→「続ける」とすると、最後に「もう一度」として2問出て、「ほかの範囲を復習する（7問）」が出る。
- 設定で場所の2つと日→英を外すと、今日の問題が英→日だけの15問になる。
