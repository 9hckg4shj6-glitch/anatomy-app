# 骨学試験対策の計画

骨学の筆記試験に向けて、このアプリで何を足すかの計画。これから数ステップの指針にする。
仕組みの細かい決まりは docs/設計.md（正本）に書き、ここは「何を・どの順で・なぜ」を書く。終わったステップには [x] を付ける。

## 公開についての方針

このアプリは公開リポジトリから誰でも見られる形で公開している。そのため、

- 過去の試験の問題文と、学生が作った分析資料の文章は、アプリにも、この文書にも、リポジトリにもそのまま載せない。
- 問われる点（どの語・どの事実か）は同じにして、文は手引き（『骨学実習の手びき』）と標準的な知識をもとに作り直す。過去の試験から持つのは「どの語が何回出たか」の数だけ。
- 大学名・出題者の名前・年度ごとの問題の並びは載せない。
- C（短文記述）は模範解答の文を見せず、「書くべき要点」の一覧で自分で確かめる形にする。

## 試験の分析（2002〜2024年度、手元の資料による）

### 形式

| | 以前（〜2021年度） | 最近（2024年度） |
|---|---|---|
| 満点・時間 | 60点（時間は60〜100分） | 100点・100分 |
| A 穴埋め | 日本語で答える | 20問×2点。日本語・英語・ラテン語のどれでもよい |
| B 用語 | 日本語⇄ラテン語 | 5問×2点。日本語→英語（またはラテン語） |
| C 短文記述 | 5問（2017年度から） | 5問×2点 |
| D 図示 | 2つから1つを選ぶ | 2問×20点＝40点。骨の名前・方向・各部の名前を日英で書き、指示線で示す |

最近の形式では D が全体の4割になった。

### 傾向

- 出題の範囲は約20年ほとんど変わらない。2024年度の A は全問が、それまでの A か、同じ資料のマーク問題で扱った点だった。B は5語中3語、C は5語中1語がそれまでに出た語。
- A の分類（21回分）: 体幹23・上肢24・下肢28・頭蓋34問。頭蓋がいちばん多い。
- A でよく出る点（5回以上）: 椎骨の数、脊柱管のつながり、椎体と椎弓、歯突起、横突孔を通る血管、岬角、耳状面、胸骨角と第2肋軟骨、肋骨角と肋骨溝、円錐靱帯結節、肩甲下窩、肩甲棘・棘上窩・肩峰、関節窩と関節下結節、上腕骨顆（小頭・滑車）、神経の溝（橈骨神経溝・尺骨神経溝）、橈骨粗面と尺骨切痕、鈎状突起と尺骨粗面、手根骨の並び、寛骨（3つの骨と月状面）、ヤコビー線、粗線・殿筋粗面・内転筋結節・恥骨筋線、脛骨粗面・ヒラメ筋線・腓骨切痕、トルコ鞍のまわり、頭蓋底の孔と通るもの（正円孔・卵円孔・棘孔）、大後頭孔と舌下神経管、眼窩をつくる骨、下顎孔とオトガイ孔。
- A は「孔・溝・管と、そこを通る神経・血管」をよく問う。
- B は特徴のある名前の語（梨状口・烏口突起・頬骨弓・鎖骨・矢状縫合・胸骨角）と骨の名前が多い。総論の語（胸郭・骨盤・縫合・骨膜・頭蓋冠）も出る。
- C は特徴のある構造と体表の目安。ヤコビー線（5回中4回）・胸骨角（3回）が最も多く、ほかに隆椎・大腿骨の内転筋結節・上腕骨の解剖頚と外科頚・胸骨下角・環椎・肩甲骨の外側角・肩峰・上肢帯・下肢帯・骨盤・滑車上孔・第三転子・ブレグマとラムダ・茎乳突孔・腰椎化・椎孔・手根溝・仙骨盤面・梨状口。
- D は長い骨が多い（上腕骨・橈骨と尺骨・大腿骨は各4回、脛骨と腓骨・肩甲骨・軸椎・下顎骨は各3回）。ほかに環椎・胸椎と腰椎・手根骨・足根骨・寛骨・眼窩・頭蓋底・胸骨・鎖骨・膝蓋骨。

### アプリとの照らし合わせ（2026-10-28）

試験に出た語約270をアプリの語（1,471語）と照らした。約200は収録済みで、ラテン語名もほぼすべての語に付いている。足りないのは次の約60語。

- 頭蓋底の孔・裂・溝とトルコ鞍のまわり（今までモデルが粗いとして見送っていた）
- 総論の語（胸郭・骨盤・頭蓋冠・上肢帯・下肢帯）、骨がつくる管と線（脊柱管・分界線・ヤコビー線・胸骨下角）
- 骨の部位（仙骨管・椎骨動脈溝・腸骨翼・仙骨盤面・手根溝・上腕骨顆・肩甲骨の外側角・関節面など）

## ステップ

### [x] ① 足りない語と「通るもの」の問い方

- 頭蓋底・眼窩・口蓋・頭蓋冠の内面の部位をピンで足す。孔の形がモデルで開いていない所（正円孔・棘孔・視神経管など）も、周りとの位置関係から位置を示し、説明に「模型では孔が見えにくい」と書く。
- 総論の語を、骨の組み合わせの語として足す（胸郭＝肋骨・胸骨・胸椎、骨盤＝寛骨・仙骨・尾骨など）。
- 骨がつくる管と線（脊柱管・分界線・ヤコビー線・胸骨下角）は、局所解剖の仕組み（囲みの線・断面）で示す。
- 体幹・四肢の足りない部位をピンで足す。
- 孔・管・溝の語に `passes`（通るもの）を書き、新しい問い方「通るもの」（4択）を足す。筋の支配神経と同じく、位置→名前を覚えてから出す。今ある孔・溝の語（横突孔・肋骨溝・オトガイ孔・篩板など）にも書く。
- 第三転子・滑車上孔のような変異は、関係する語の説明に書く。
- 骨膜・緻密質・縫合など、3Dで示しにくい総論の語は②の B で扱う。

完了の条件: 試験に出た語のうち、3Dで示せる語はすべて図鑑で引けて、レッスンと復習に出る。npm run check が通る。

### [ ] ② 「骨学試験」フォルダー（A・B・C）

- 内容は content/exam.json（新設）。項目ごとに、関係する語ID・過去の出題回数・最後に出た年度の古さ（数だけ）を持つ。
- **A 穴埋め**: 自作の文の空欄を入力で答える（日本語・英語・ラテン語のどれでも正解）。答えたら3Dでその部位を示す。出題回数の多い順に並べ、文ごとに FSRS で復習する。
- **B 用語**: 骨の語の日→英のつづり入力（今ある `ja2en` を骨に絞る）と、英語・ラテン語→日本語。3Dの部品の無い総論の語（骨膜・緻密質・海綿質・骨髄・骨端線・縫合・関節軟骨など）は、ここで用語だけのカードにする。
- **C 短文記述**: 語を見て頭の中で説明してから、要点3〜4個のチェック表を開いて自分で採点する。対象は過去の語と、出題の形から予想される語。
- ホームに「骨学試験」フォルダーを置き、A・B・C の進み具合（覚えた割合）を出す。図鑑とカードに「試験に出た」の印を付ける。

### [ ] ③ D 骨まるごと（図示）

- 骨を選ぶと、試験の向き（前面・後面など）で出し、試験で描くべき部位に番号のピンを立てる。番号ごとに日本語と英語で答える。
- 紙に描いてから、番号付きの図と見比べて自分で確かめる型。
- 骨をランダムに回したり左右を入れかえたりして、左右と上下・前後を当てる問題。
- 骨ごとに「描くべき部位」の一覧を持つ（手引きと過去の出題から）。対象は上腕骨・橈骨と尺骨・大腿骨と膝蓋骨・脛骨と腓骨・肩甲骨・環椎と軸椎・胸椎と腰椎・寛骨・手根骨・足根骨・下顎骨・眼窩・頭蓋底・胸骨・鎖骨。

### [ ] ④ 対で覚える・数と並び・体表の目安

- 対で覚える: 紛らわしい語を並べて違いを答える（橈骨の尺骨切痕と尺骨の橈骨切痕、正円孔・卵円孔・棘孔、上眼窩裂と下眼窩裂、解剖頚と外科頚、大結節と小結節、肋骨突起・横突起・副突起、弓状線と恥骨櫛、内果と外果）。
- 数と並び: 椎骨の数、手根骨・足根骨の並び、眼窩をつくる7つの骨、無対の頭蓋骨、頭蓋の15種23個、分界線のたどり方。3Dで順に押して答える問題も。
- 体表の目安: ヤコビー線＝第4腰椎の棘突起、胸骨角＝第2肋骨、胸骨下角＝第10胸椎、肩甲骨の下角＝第7胸椎の棘突起、肩甲棘の内側端＝第3胸椎、隆椎、剣状突起＝第9胸椎。

### [ ] ⑤ 模擬試験と試験日の計画

- 模擬試験: A 20問・B 5問・C 5問・D 2問を100分で。自分で採点し、100点満点の点数を記録する。
- 試験日の計画: 試験日を入れると、それまでに試験の項目を一度は学べるよう、1日の新しい問題の数を決める。
