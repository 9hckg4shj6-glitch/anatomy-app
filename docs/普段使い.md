# 普段使い（計画と決まったこと）

## Context（なぜやるか）

内容は 2,511語・302レッスン・31臓器・平面図115枚、問い方は22種類まで増え、使いやすさの見直し（docs/使いやすさ.md のその1〜7）も一通り済んだ。それでも「毎日開きたくなる」にはまだ届いていない。普段使いを妨げているのは「足りない」ではなく **「多い・重い・たまる・途切れる」**。これからの編集は、機能や内容を足すことより、毎日の1回を軽くすることを先に置く。

2026-11-16 に、画面の見本（Design の Artifact「解剖3D 画面の見本」）を作って利用者に見てもらい、次の形に決めた。

## 方針（これからの編集すべてに当てる決まり）

1. 毎日の輪を一番に守る: 開く → 1タップで1問目 → 3〜5分で「今日は終わり」→ 明日また開く。
2. 足す前に、減らす・隠す・既定を良くする。新しい機能はホームの入口を増やさず、今ある画面の中に入れる。
3. 量はアプリが引き受ける。たまった数を見せて責めない。
4. 学生の暦で動く（範囲と日付を入れれば今日の分が決まる）。
5. どの端末でも続きから。
6. 内容を足すときは出会う道（どのコース・レッスンで出るか）も一緒に決める。
7. まちがいを見つけた人がその場で知らせられる。
8. 測ってから決める。

## 決まったこと（2026-11-16）

- **画面は下のタブ4つ**「今日・学ぶ・調べる・記録」（iPad・PC は左の細い帯）。2026-11-20 に設定を記録から分けて5つにした（下の「記録と設定を分ける」）。ホームに戻らずに行き来する。レッスン・復習を解いている間はタブを隠す。
  - 今日（#/）: 回る人体と、今日の一手1つ（今日の復習 N問＝押すとすぐ1問目、無ければ次のレッスン）・続きから・骨学試験の日。
  - 学ぶ（#/study）: 次の1つ、レッスン・臓器の図・演習・骨学試験・語根カード。**臓器の図は学ぶに置く**。
  - 調べる（#/look）: 検索・最近見た語・図鑑・★を付けた語。2026-11-20 に見直した（下の「調べるの見直し」）。
  - 記録（#/records）: 今週・今日・学んだ語、骨学試験の日、進捗・設定・出典。
- **はじめての人には全部を並べず、次の1つだけ見せる**（内容は減らさない）。
  - はじめに1回だけコースを選ぶ（#/start）: はじめての解剖（初心者コース）／授業に合わせて自分で選ぶ。（2026-11-17 に「骨学試験の対策」のコースをやめた。骨学試験は学ぶから使う）初心者モード・詳細モードはコースから決める。選んだら3語だけの短いレッスンを通す。
  - 学ぶの一番上はそのコースの次の1つだけ。大きな数（全部で何語・何レッスン）は出さない。
  - 使う時が来たら出す: 何も学んでいなければ、学ぶにはレッスンと臓器の図だけ。演習・骨学試験・語根カードは1つ学んでから。設定の「すべての学び方を出す」でいつでも出せる。
- **演習は「おまかせ」にしない**（知識の足りない人に合わない）。入口の一番上は「終えたレッスンから選ぶ」。その下に苦手な語・★を付けた語・範囲を細かく選ぶ（今までの一覧）。学んでいない語は自分で選んだときだけ。
- **骨学試験は試験対策として独立のまま**。今日の復習や目標にはまとめない。
- レッスンの一覧は系統を上のボタンで選び、まとまりごとに道すじ（済み・途中・まだ）で並べる。始めの画面は語の一覧・初めの説明の1段落・問い方の4つの切りかえ・「始める」と「確認テストだけ」。
- 語のカードは 名前と★ → 英語と発音・語根 → 覚えること（説明）→ 起始・停止など → メモ → くわしく（漢字・語源・置き方。開いたままにできる）。図鑑では部位・関係する語を1行ずつの一覧にし、「この語を演習」を置く。

## スタート画面（2026-11-17 に決めたこと）

見本は Design の Artifact「からだ見聞録 スタート画面の見本」。基礎医学演習アプリのスタート画面にならう。

- アプリの名前は暫定で「からだ見聞録」（もとは「解剖学 3D単語帳」）。
- はじめて開いた人: ① 名前 → ② 所属 → ③ コース（はじめての解剖／授業に合わせて自分で選ぶ）→ 3語のレッスン。
  - ① 上に本物の3D（骨格・筋を選べる）がゆっくり回る。名前は必須（ニックネーム可、24文字まで）。下に「前の記録を読み込む」。
  - ② 所属は大学・学部学科・学年の3つの欄を1枚の表に畳み、押すと下から出る一覧で選ぶ。**大学は打たずに選ぶ**。医学部（医学科）のある大学82校（81校と防衛医科大学校）を先に、地方 → 都道府県ごとに並べ、「そのほかの大学」と「一覧に無い大学（その他）」も置く。学部学科は7つ（一言の説明つき）、学年は1〜6年とその他。
  - **所属はできるだけ入れてもらう**: 飛ばせない。あてはまらない人は「その他」を選ぶ。
- **所属は管理者のデータ収集に使う**: 名前・大学・学部学科・学年を管理者に送る（学習の記録は送らない）。画面にその旨を書く。
- 今使っている人にも、次に開いたとき1回だけ ①② を出す（コースはもう選んでいるので出さない）。
- **「おかえり」の画面は作らない**。2回目からはスタート画面を出さず、今まで通り「今日」を開く。
- 名前と所属は 設定 でいつでも直せる。
- 「骨学試験の対策」のコースはやめた（骨学試験は学ぶから使う。5a0ab1e）。
- 送り先は基礎医学演習アプリの Supabase に相乗り（表 anatomy_profiles、管理画面に「からだ見聞録の利用者」）。2026-11-17 に実装（docs/設計.md）。

## はじめての人への案内（2026-11-18 に決めたこと）

「はじめて開いた人に、どんな機能があるのか・自分の目的に合わせてどう使えばいいのかが分かりにくい」という声があり、はじめての人として iPhone と iPad で通して見た。分かったこと:

- はじめにの3枚目は「何のために使いますか？」と聞くのに、選択肢は覚える量の段だけで、目的（骨学試験・実習で調べる など）が出てこない。2年生に「標準 おすすめ」と出しながら「はじめての解剖」が選ばれていた（不具合）。
- 何ができるかを一度も見ないまま3語のレッスンに入る。学ぶでは演習・骨学試験・語根カードが1つ学ぶまで隠れ、あることも分からない。「レッスン」と「臓器の図」、「今日の復習」と「演習」の違いがどこにも書かれていない。
- 使い方の説明が無い（「?」は3Dの動かし方だけ）。目的に合わせて変える所（試験の日・コース）が「記録 › 設定」の奥。

決めたこと（3つとも利用者が選んだ）:

- **はじめにの3枚目は「使う目的（いくつでも）」と「覚える量」**。目的は 授業の予習・復習／骨学試験の対策／実習・講義の合間に調べる／CBT・国試の前に見直す の4つ（src/purposes.ts、設定 `purposes`）。覚える量は目的と学年からすすめ（1年生で骨学試験・見直しを選んでいなければ「はじめての解剖」、ほかは「標準」。「すべての語」はすすめない。`recommendCourse`）、自分で選び直すまではおすすめを選んでおく。骨学試験を選んだら試験の日も聞く（空でもよい）。はじめての解剖で骨学試験を選ぶと「標準とすべての語で使えます」と出す。
- 目的は機能を出す・隠すことには使わない。コースのおすすめ・「あなたの使い方」・使い方のページの並びにだけ使う。設定の「コースと使う目的」と使い方のページでいつでも足し外しできる。今使っている人には聞かない（空のまま）。
- **学ぶの学び方はいつも全部**、「こんなときに」の一言つき。まだ使えないものは鍵を付けて押せなくし、どうすれば使えるかを書く（何も学んでいないときの演習、はじめての解剖の骨学試験・語根カード）。設定の「すべての学び方を出す」（`showAllWays`）はやめた。
- **使い方のページ（#/guide）**: しくみ（レッスン → 今日の復習 → 演習、調べるはいつでも）・目的から選ぶ（目的のチップと、目的ごとの手順。選んだ目的を先に開く。手順には押すとその画面へ行くリンク）・4つのタブとその中身・ことばの意味（レッスン・今日の復習・演習・問い方・コース・覚えること・模式）・3Dとキーボード。入口は上の帯の「? 使い方」（解いている間とはじめには出さない。3Dの右上の「?」＝3Dの動かし方と見分けるため字を添える）・記録のタブ・学ぶの一番下・今日の「はじめに」の札・設定（2026-11-20 に上の帯・記録・3Dの「?」の3か所に絞った。「画面の分かりにくさの見直し」）。
- **はじめの1回の案内**: 3語のレッスンの終わりに「あなたの使い方」（選んだ目的ごとに初めの2つの手順。目的が無ければ授業の予習・復習）と「使い方をすべて見る」。各タブの一番上に1行の説明（src/ui/tab-intro.ts。× で閉じる・5回見たら出さない。使い方のページの「タブの説明をもう一度出す」で戻せる）。

## 使い方ガイド（2026-11-18）

「文字の説明だけでなく、アニメーションや図も入れた本格的な使い方ガイドを」という依頼で、使い方のページ（#/guide）を作り直した。

- **章立てと目次**: 01 毎日の使い方 → 02 レッスンの流れ → 03 問い方と答え方 → 04 復習のしくみ → 05 3Dの動かし方 → 06 4つのタブ → 07 語のカード → 08 そのほかの学び方 → 09 目的別の使い方 → 10 困ったとき → 11 ことばの意味 → キーボード。一番上に、回る骨格と「3Dで場所を見る・名前を覚える・忘れる前に復習」。"#/guide/<章>"（day・lesson・ask・memory・3d・tabs・card・more・purpose・faq・words・keys）でその章を開く。目次から押したときは画面を作り直さずにずらす（ctx.stay）。3Dの「?」（操作の一覧）から「動く見本で見る」で 05 へ。
- **動く見本**（src/ui/guide-demos.ts・src/ui/guide.css）: 画面の見本は HTML と CSS で描き、3Dの所はアプリの3Dを撮った絵（public/guide/*.webp。scripts/guide-images.mjs）。指の丸とタップの輪が押す所（ボタン・選択肢・骨）の中にあり、押した時に答えが緑になる・骨が光る。
  - 毎日の使い方: 端末の枠の中で 今日 → 今日の復習を押す → 4択に答える → おわり を12秒でくり返し、横の手順4つが同じ時に光る。
  - レッスンの流れ: 始めの画面・1語ずつ見る・確認テスト・復習に入る の4段。押して切りかえ、画面に入っている間は6秒ごとに自動で進む（押したら止める）。
  - 問い方: 位置→名前・名前→位置（3Dをタップ）・日本語→英語 の3つの見本と、答えたあと（正解・惜しい／自信がなかった・不正解）で次に出る日がどう変わるか。
  - 復習のしくみ: 思い出せる見込みの曲線（FSRS の忘れ方 R = (1 + 19/81・t/S)^-0.5。90% に下がるころに出す）を描き、復習のたびに次までの日が 1日 → 3日 → 8日 → 20日 と長くなる例と、復習しないときの下がり方。
  - 3Dの動かし方: 回す（骨格が回る）・拡大・ずらす・名前を見る の4つ。スマホ・iPad とパソコン（マウス）で説明と指／矢印を切りかえる（はじめは端末に合わせる）。向きの目印（前から見ているときは体の右が画面の左）の図。「3Dで試してみる」で3Dを出し、タップした部位を光らせて名前を出す。
  - 4つのタブ: 端末の見本で、指がタブへ動いて中身が替わる（自動でめぐる。チップを押すとそのタブ）。横にそのタブの中身と行き先。
  - 語のカード: 大腿骨のカードに番号 1〜7（読みと系統・名前と☆・英語と発音・語根・覚えること・メモ・くわしく）を付け、下に説明。
  - そのほかの学び方: 臓器の図・演習・骨学試験・語根カード・図鑑と調べる・進捗 を絵つきのカードで（押すとその画面）。
- **3Dと連動**: PC・iPad の横では、読んでいる章に合わせて左の3Dが替わる（はじめ・毎日・タブなどは回る骨格、レッスン・問い方・語のカードは大腿骨を光らせて名前、3Dの動かし方は止めて自由に動かせる）。スマホでは3Dはたたんだまま。
- **動きは見えている間だけ**: 見本が画面に入っている間だけ動かす（IntersectionObserver で .is-on）。端末の「視差効果を減らす」（prefers-reduced-motion）では動かさず、答えの絵（光った骨・緑の選択肢）で止める。自動で進む見本も進めない。
- 困ったとき（よくある質問）9つ: 復習がたまった・当てずっぽうで正解した・新しい語の数・コースを変える・機種変更・オフライン・3Dで迷った・文字の大きさと英語・3Dが出ない。
- 見本の絵は、3Dや画面を変えたら撮り直す（`GUIDE_URL=… PLAYWRIGHT=… node scripts/guide-images.mjs`）。進捗の絵の色は見本（実際の記録ではない）。

## はじめての人の使いにくさの見直し（2026-11-19）

はじめての人（記録なし）として iPhone（390×844）・小さい iPhone（375×667）・iPad 横（1180×820）で通して見て、使いにくい所を洗い出した。そのうち「はじめの数分」と「レッスンと問題」をまず直した（画面の分かりにくさ＝「3Dを出す」の帯・3Dの「⤢」「?」と向きの目印・ヘルプの入口の多さ・臓器の図の一覧・言葉・最初の読み込みの重さ などは次の「画面の分かりにくさの見直し」で）。

分かったこと:

- 最初の3語が「上・下・前」（矢印の図の語）で、3Dをタップして答える問題を一度も体験しないまま終わる。
- 何ができるかを見る前に、名前と所属で2画面を使う。1/3 のボタンが「はじめる」なのに始まらない。
- 名前を入れるのでアカウントがあると思いやすいが、記録はこの端末の中だけ（14日たつまで知らせない）。
- iPhone の Safari では「ホーム画面に追加してから始めて（記録が別々）」の案内が、はじめにと3語を終えたあとに出る。
- 3語の終わりは「忘れかけたころに出ます」と言うのに、すぐ「今日の復習 3問」。15語のレッスンを1つ終えると「今日の復習 20問・約7分（復習 0・新しい 20）」。
- 名前→位置は、タップした瞬間に答えが決まる（回そうとして触れただけで不正解）。
- 英語の発音が最初から自動で鳴る。小さい iPhone では4択の4つ目と「わからない」が画面の外。

決めたこと（4つは利用者が選んだ）:

- **はじめの順は「先に3語を試す」**: はじめ（回る3D・できること3つ・「まず3語を試す（約1分）」）→ 3語のレッスン → 名前 → 所属 → 目的・覚える量・英語の発音 → 準備ができました（あなたの使い方と、最初／続きのレッスン）。名前と所属が必須なのは同じ（3語のあとも、入れるまでスタート画面に戻る）。「試さずに始める」で名前からも始められる。今使っている人で名前がまだの人は、今までどおり名前と所属だけ。
- 3語は初心者コースの「脚の骨」の大腿骨・膝蓋骨・脛骨（正面から見えて、名前→位置を出せる）。確認は位置→名前と名前→位置を交互に。
- **今日学んだ語は「仕上げ」として別の枠に**: 今日の復習は前の日までに学んだ語だけ。今日のレッスンで学んだ語の問題（ほかの問い方と、確認テストの答えの10分後の解き直し）は「仕上げ 今日学んだ語 N問・やらなくてよい」（#/review/finish）。今日の画面・レッスンの終わり・復習の終わりに行で出す。解かなければ次の日から今日の復習に出る。新しい問題の上限（1日20問）は今日の復習と仕上げで別々に数える。学び直した語は初めに学んだ日時のまま（仕上げに移さない）。レッスンだけの日の今日の札は「今日の分は終わりました」。
- **名前→位置は選んでから決める**: 1回目のタップは青く光るだけ（名前は出さない。骨の部位の問題はタップした点に青い印）。同じ所をもう一度タップするか「これで答える」（Enter）で決まる。同じ所は、語の問題なら同じ語、骨の部位の問題なら同じ部位か 1.2cm 以内。
- **英語の発音は、はじめにで聞く**: 目的と覚える量の画面に「自動で鳴らす／🔊を押したときだけ」（選んであるのは今までの「自動で鳴らす」）。3語の間は鳴らさない。
- 名前の画面に「記録はこの端末の中に保存（アカウントは無い）。機種を変えるときは 記録 › 設定 から書き出して読み込む」。iPhone・iPad のブラウザで開いたときは、はじめの画面に「先にホーム画面に追加」を出す。
- 小さい画面: はじめの「まず3語を試す」・目的の画面の「この使い方で始める」・準備の画面のボタンを画面の下に留める。背の低い画面（高さ 700px まで）では3Dを 38svh（今日は 50svh）にし、4択を詰める。今日のタブの1行の説明は今日の札の下へ。

## 画面の分かりにくさの見直し（2026-11-20）

「はじめての人の使いにくさの見直し」で残した「画面の分かりにくさ」（洗い出しの 10〜19）を直した。4つは利用者が選んだ（帯・臓器の図の一覧・使い方の入口・読み込み）。

分かったこと:

- スマホでは、調べる・記録・設定など3Dの要らない画面の上にも黒い帯「3Dを出す ▾」があり、何の帯か分からない。

## 端末をまたぐ（同期）（2026-11-20）

「端末間同期、Google アカウントからログインできるように」という依頼で、段階の5を実装した。

### 決めたこと

- ログインは Google だけ。基礎医学演習アプリの Supabase（すでに Google ログインが有効）を借りる。同じ Google アカウントなら同じ利用者（auth.users）だが、記録の表は別（anatomy_sync）なので混ざらない。ログインの保存場所は localStorage の anatomy-auth（同じドメインの基礎医学演習アプリとログインを分ける）。ログインしなくても今までどおり端末の中だけで使える。
- 戻り先: 公開先（9hckg4shj6-glitch.github.io/anatomy-app/）は Supabase の Site URL（基礎医学演習アプリ）と同じホストなので、Redirect URLs を足さなくても受け付けられる（/auth/v1/verify で確かめた）。開発は localhost:5173 が登録済み（5179 は未登録）。
- 同期するもの: 覚え具合・解いた記録・学んだ語・設定（★とメモ・名前と所属・コース・目的など）。端末ごとのもの（端末ID・その日に開いたこと・「ホーム画面に追加」の案内・同期の状態 sync.…）は同期も書き出しもしない（db.ts の isDeviceSetting）。名前と所属の「送った版」（sentAt）は端末ごと（受けた端末は、次に開いたときにその端末の分として管理者へ送る）。
- 合わせ方: 同じ行は端末で変えた日時の新しい方（覚え具合は最後に解いた方、取り消しも「消した」として届く）。解いた記録は ID が違えば両方残る。学んだ語は早い方の日時。設定は行の updatedAt で比べ、アプリが自分で入れる初めの値（モードの初めなど。settings.ts の loadPreferences）は古い日時（DEFAULT_STAMP）で入れて、ほかの端末で選んだ値に負けるようにする。
- はじめてログインした端末は、その端末の記録とアカウントの記録を合わせる（どちらも消えない）。前に別のアカウントでログインした端末では「この端末には ○○ の記録があります」と出し、「△△ の記録に切り替える（この端末の記録を消す）」か「ログアウトする」を選ぶ。
- ログアウトは「残す（この端末だけで続ける）」か「この端末から消す（共用の端末など）」。残したときは変えた行を残し続け、同じアカウントでログインし直すとそのあとの分も送る。
- 入口: 設定の一番上「アカウントと同期」（#/settings/account）、はじめに（はじめと名前の画面の下「ほかの端末で使っている人は Google でログインして続きから」。受けて名前・所属・コースがそろったら今日へ）。LINE などのアプリの中のブラウザでは Google がログインを断るので、その旨を出す。ログイン中はホームの「記録を書き出しましょう」を出さない。

### しくみ

- サーバー: 基礎医学演習アプリの supabase/migrations/020_anatomy_sync.sql。表 anatomy_sync は人ごとの「束」1行（解いた記録は日ごと e:2026-11-20、覚え具合 s:0〜63・学んだ語 l:0〜15・設定 c:0〜7 はキーを散らす）。束の中は { キー: { c 変えた日時, v 行（消したら null）, d 送った端末, s 受けた番号 } }。RPC は anatomy_sync_push（キーごとに c の新しい方。先の日時は今に直す。人ごとに1つずつ）と anatomy_sync_pull（前回の番号より後の分を束の番号の順にページで。1回の受け取りは、はじめのページの head までの分。自分の端末の分は除く）。表は直に読めない。
- 端末: db.ts の Dexie の一番下（DBCore の middleware）で4つの表への書き込みを outbox（version 2 で足した表）に残す（ログインしたことのある端末だけ。同期で受けたものを書くトランザクションは quietTransaction で除く）。src/sync.ts が受けて（まだ送っていない自分の変更の方が新しければ自分のを残す）から送る。行のキーと解いた記録の cardId は送らない（容量）。src/account.ts がログイン（supabase-js はログインしたことのある人だけ読み込む。PKCE で ?code= を受け、# はこのアプリの画面のまま）と同期の時機（変えてから15秒・画面を離れたとき・画面に戻ったとき・通信が戻ったとき・開いている間は5分ごと）を受け持つ。受けて変わったら anatomy:synced（今日・学ぶ・記録・進捗・設定・はじめには描き直す）。
- サーバーの準備がまだ（020 を適用する前）は「同期のサーバーの準備がまだです」と出し、記録は端末に残る（適用すれば自動で始まる）。

### 確かめたこと

- tests/sync.test.ts（偽のサーバーと IndexedDB を分けた2つの端末: 届く・取り消し・通信の無い所で両方が解いた・はじめての端末の合わせ方・初めの値が負ける・ページの間に束が新しくなっても落とさない・何百日分）、tests/account.test.ts（戻ってきたときのアドレス・知らせの文）。
- 020 の SQL を PGlite（Postgres 17）で: 認証・形の検査・新しい方が残る・ページ・権限（anon は呼べない、表は読めない）。同期のしくみをその SQL につないで2つの端末が同じになること。
- Chrome で（Playwright）: 本物の supabase-js で、Google の画面と Supabase の認証は偽物、RPC は PGlite の 020 につないで、A がログインして送る → 新しい端末 B ははじめにからログインして名前・所属・コース・学んだ語・★とメモを受けて今日へ → B で解いた分が A に届く → B を「この端末から消す」でログアウト → A を残してログアウトし、別のアカウントでログインすると切り替えの確かめが出て、切り替えると空の記録から。
- 重い人（2,500語×3つの問い方＝7,500問・解いた記録3万・学んだ語2,500）: Chrome ではじめの送り 約2秒（52回・約9.8MB）、1問解いたあと 約10ms、新しい端末で全部受けるのに 約1〜2秒（WebKit は 約2.7秒・2.3秒）。サーバーの大きさは 600語の分で 約0.7MB（2,500語なら 約3MB）。ふつうの人はこの数分の1。
- 本物の Google ログインと、iPhone のホーム画面のアプリから Google へ出て戻る流れは、公開してから実機で確かめる。

## 設定の見た目の見直し（2026-11-20）

「設定の項目の欄などが雑。もっと見やすく、高級感があるように」という声で、設定（#/settings）の見た目を組み直した。前は線で区切った長い1枚に、丸いチップと灰色の長い説明が並ぶだけだった。

- **見出しとカードの行**（src/ui/settings-kit.ts）: 小さな灰色の見出しの下に、角の丸い白いカード（薄い影）。中は行で、行の間は左を空けた細い線。説明はカードの下の小さな注にまとめ、行には一言だけ。
- **操作の形を中身に合わせる**: 2択（自動で次へ・発音・英語を併記・向きの目印）はスイッチ（行ごと押せる。role="switch"）。数や大きさ（1日の数・復習の区切り・文字の大きさ）は切り替えの帯（白い札が選んだ所へすべる）。コースは1つを選ぶ行（右に✓・題をアクセントの色・説明の頭に語の数の札）。使う目的と学ぶ問い方はいくつでも選ぶ行（右に丸と✓。問い方の行に何をする問題かの一言 KIND_HINTS）。押すとすることは色の字の行（危ないものは赤）。
- **名前と所属・アカウント**: 名前の頭の1字の丸と、名前・所属（押すと直す）。ログイン中は Google の札と、同期の状態を色の点（緑＝同期済み・黄＝待ち/準備中/失敗・点滅＝同期中）で。ログインしていないときは説明と全幅の「Google でログイン」。
- 記録の書き出し・読み込みは「最後に書き出した日」と2つの行。オフラインは状態と系統の札・「すべて保存（約○MB）」の行。骨学試験の日は行の右に日付と「消す」。
- スイッチと切り替えの帯は押したその場で見た目を変え、描き直さない（動きが途切れない）。コース・問い方・目的は今までどおり描き直す。使い方のページの目的は今までどおりチップ（purposeChips）。

## 調べるの見直し（2026-11-20）

「調べる項目をもっと簡便に、クオリティ高く」という声で、調べる（#/look）を見直した。前は検索・図鑑・★だけで、結果は語の並び順のまま（「ちょう」で腸骨が先、「頸動脈」では総頚動脈が下の方）、名前と英語だけなので意味を知るには図鑑を開いて3Dを待つ必要があり、コースの外の語は引けず、打ちまちがいは「見つかりませんでした」だけだった。

- **当たり方のよい順**（src/search.ts の lookup）: 名前がそのまま同じ語 → コースの語 → コースの外の語 の順で、その中は「頭から当たる」→「英語の語の頭に当たる」→「途中に当たる」。同じなら必修・基礎の語、短い名前が先。日本語の当たりは英語より少し上。演習・レッスンの一覧・図鑑の検索（searchTerms）も同じ並びに（こちらは今までどおりコースの語だけ）。
- **表記ゆれをそろえる**（fold）: 頸と頚・彎と弯・鉤と鈎・鼠と鼡、ぢ・づ、区切り（空白・中黒・ハイフン・かっこ）を除く（sacro iliac で sacro-iliac joint）。読みはローマ字でも（jouwan → じょうわん。英語として読めない並びはローマ字にしない。英語の当たりが先）。空白で区切ると、どの言葉も当たる語（「上腕 動脈」）。自分のメモでも探す。
- **結果の行**: 系統の色の点・名前と英語（打った所に薄い色）・**覚えること**（無い語は説明の最初の1文、2行まで）・読みと場所。ラテン語・英語の別名・メモで当たったときはそれも。図鑑を開かなくても意味が分かる。件数（うちコースの外）を上に、40語より多いときは「さらに表示」。
- **コースの外の語も引ける**: 調べるだけは全部の語から探し、コースの外の語には「コースの外」の札。初心者モードでも授業で出た語を引ける。
- **もしかして**（suggest）: 見つからないとき、1字ちがい（7字以上は2字）で近い語を5つまで（上椀骨 → 上腕骨、humerous → humerus）。
- **何も打っていないとき**: 最近見た語 → ★を付けた語 → **系統から探す**（色の帯の札。#/look/<系統ID> でその系統の語をレッスンごとに覚えることと一緒に。3Dは読まない。上の帯は「‹ 調べる ／ 系統の名前」）→ 3Dで調べる（図鑑・臓器の図）。★が無いときの説明は一番下に。
- **戻っても続きから**: 結果から図鑑を開いて「‹ 調べる」で戻ると、打った言葉と結果のまま（アプリを開いている間だけ）。PC では検索欄の文字を選んだ状態にして、すぐ打ち直せる。↑↓ で結果を選び Enter で開く（選んでいる行に薄い色）、Esc で消す。
- tests/look.test.ts。使い方の「調べる」の見本と項目に系統から探すを足した。
