# 緻密なモデル（アトラスに近づける）

アトラス（Visible Body の Human Anatomy Atlas）がこのアプリより上なのは、骨格・臓器・神経・血管の形の細かさにある、という声を受けた計画。

## 今の様子（2026-11-16 に見直した）

- 全身の見た目: 詳細モードでは、骨・筋・血管・神経の全身はそろっている（初心者モードは語にした形しか読まないので、筋のすき間から骨が見える）。
- 素材の上限: 自由に使える全身の形で、今の BodyParts3D（3.0 の95%減の版を重ねたもの）と Z-Anatomy より細かいものは見つからなかった。
  - BodyParts3D は 2.0〜4.0 のどれも 95% か 99% 減らした版しか配られていない。
  - HuBMAP の Human Reference Atlas の参照臓器（CC BY 4.0、https://lod.humanatlas.io/ref-organ）は、Visible Human から作ったなめらかな模式の形（心臓は部屋・弁・乳頭筋の14部品、血管は106本）。脳の回の区分（Allen、283部品）と眼の中（毛様体突起・シュレム管など23部品）は細かいが、ほかは今の形より粗い。
  - Open 3D Model（オランダの解剖学教室）は Z-Anatomy がもとの CC BY-SA。
- 差が大きいのは「語はあるのに立体の形が無く、平面図だけで示している肉眼で見える構造」。2026-11-16 の時点で:
  - 心臓の中: 腱索・心室中隔・心房中隔・肉柱・中隔縁柱・卵円窩・線維輪・刺激伝導系（洞房結節〜プルキンエ線維）・心膜の層・心内膜（20語）
  - 耳: 外耳道・鼓室・半規管（前・後・外側）・卵形嚢・球形嚢・前庭窓・蝸牛窓・蝸牛管
  - 眼: 瞳孔・後眼房・黄斑・中心窩・視神経円板
  - 脳と脊髄: 硬膜・くも膜・軟膜・嗅球・嗅索・大脳動脈輪・静脈洞交会・大大脳静脈・脊髄の索
  - 喉と鼻: 声帯ひだ・声門・鼻中隔・硬口蓋・上鼻道
  - 神経: 頚神経叢・横隔神経・腰神経叢・仙骨神経叢（Z-Anatomy にも形が無い）、腕神経叢の束
- だから「緻密さ」は、素材を探すのではなく、今の形をもとに足りない形を自分で作る（腎臓・肺区域・鼻腔でしたのと同じやり方）。

## 作り方の決まり

- 元にする形のライセンスを保つ: BodyParts3D だけから作る形は CC BY 4.0 のまま BodyParts3D の GLB に、Z-Anatomy の形を使う形は CC BY-SA 4.0 の `-za` の GLB に入れる。
- ボクセル（0.5mm）で区分して面を作り直し、元の面から 0.9mm 以内の点は元の面に吸い付ける（scripts/kidney/kidney.py の考え方）。細い管（神経・伝導系・線維輪）は道すじの上に管の形を直接作る。
- 実物の数や向きを写せない形（肉柱・櫛状筋・プルキンエ線維など）は「模式の形」とレッスンの説明に書く。
- 形を作ったら、確かめる絵（断面と立体）を data-raw/<臓器>/ に書いて見る。

## その1 心臓の中（2026-11-16）

  - 心房中隔: 右心房と左心房の内腔からともに 7mm 以内（2つの壁の間の細いすき間は閉じてから見る）。
  - 動脈円錐: 右心室の壁のうち肺動脈弁の中心から 24mm 以内で、三尖弁の尖の上端から 14mm 下より上。

- 内面のつくり（壁からの距離の場に沿って道を引き、半分ほど壁に埋まる太さで塗る）: 左心室の肉柱150本（細く、心尖ほど網目）、右心室の肉柱130本（太く長い。流出路には作らない）、中隔縁柱（右心室の中隔の中ほどから前乳頭筋の根もとへ内腔を横切る柱と、室上稜へ向かう隆起）、分界稜（上大静脈の口から下大静脈の口へ）と櫛状筋11本（分界稜から右心耳へ）。

- 刺激伝導系（管の形）: 洞房結節（分界稜の上端の心外膜の下の紡錘）、房室結節（冠状静脈洞の口と中隔尖の付け根の間）、房室束（心室中隔の上の縁へ）、右脚（右心室の中隔の心内膜の下を中隔縁柱へ、その中を前乳頭筋へ）、左脚（前枝・後枝を前・後乳頭筋へ、中隔の枝を心尖へ）、プルキンエ線維（脚の先から心内膜の下に網のように110本）。
- 線維輪: 房室弁は尖の膜のいちばん心房側の点を角度ごとに拾った輪、半月弁は弁のいちばん心室側の輪。

## その2 耳（2026-11-25）

scripts/ear/（export.mjs → ear.py → index.mjs。index.mjs は scripts/za/index.mjs の loadZa から読む）。Z-Anatomy の蝸牛・前庭の形を分けてもとにするので CC BY-SA 4.0 として Z-Anatomy の GLB（sensory-za）に入れる。部品ID は ZE_…。左の耳は左右を反転して右と同じ手順で作り、反転して戻す。

- 元の形: Z-Anatomy の「前庭」は前庭と3つの半規管が1つの形、「蝸牛」はらせんの管で、2つは蝸牛の根もとの開いた輪でつながっている。前庭の形にはもう1つ開いた輪があり、それがアブミ骨底のはまる前庭窓。どちらも骨迷路の空所（外リンパの所）の形なので、0.1mm のボクセルにして分ける。
- 骨迷路:
  - 前庭と半規管: 壁から 1.0mm より深い所（前庭の芯）から形の中を 2.0mm 広げ、その外に残る管が半規管。管のかたまりは2つ（外側半規管と、総脚でつながった前・後半規管）。前・後は2つの平面に交互に当てはめて分け（上が前。2つの面はほぼ直角になる）、両方の平面に近い所のうち上のかたまりを総脚とする。平面の交わる線は膨大部の近くも通るので、前・後・総脚はそれぞれいちばん大きなかたまりだけ残す。芯と管の間は、形の中の道のりで近い方に付ける。
  - 半規管ごとに円を当てはめ、円のまわりの角度で並べて中心線と太さを求める（前・後は総脚を通って前庭へ入る）。両端のうち太い方が膨大部。
  - 蝸牛: 前庭との境の輪からの道のりで中心線を引き、らせんの軸は中心線の平面の法線（頂の側が正）。断面の中で軸の向きに管の半径の -0.1 より上が前庭階、下が鼓室階。前庭階のうち外側の壁に寄った三角形（内の端 -0.15 から傾き 0.85 の線＝前庭膜より下）が蝸牛管。外向きはならした中心線の曲がりの外。頂の 1.5mm（蝸牛孔のあたり）と根もとの 0.5mm には蝸牛管を作らない。
- 膜迷路（模式の形。実物は骨迷路よりずっと細い）:
  - 膜半規管: 骨の管の中心線を円の外へ寄せた道に、骨の管の半径（中央値）の 0.36 倍の管。膨大部では骨の膨大部の 0.62 倍に太くし（膜膨大部）、その内側の壁に管と直角の高まり（膨大部稜）。両端を卵形嚢までのばす。前・後の膜は総脚の中を通り（膜の総脚）卵形嚢へ入る。
  - 卵形嚢: 前庭の芯から、半規管の5つの口の平均へ 35% 寄った所の、膨大部から総脚へ向かう細長い楕円体（半径 1.9×0.95×0.8mm）。球形嚢: 前庭の芯と蝸牛の口の中ほどの球（半径 0.8mm）。どちらも骨の壁から 0.12mm 離す。球形嚢と蝸牛管を細い結合管でつなぐ（蝸牛管に入れる）。
- 前庭窓: 前庭の穴（開いた輪）をふさぐ厚さ 0.3mm の板（輪の形を 1.05 倍）。蝸牛窓: 根もとから 0.6〜3.5mm の鼓室階の壁のうち、鼓膜の中心にいちばん近い所の半径 0.75mm・厚さ 0.3mm の板（前庭窓の中心から約 3mm の後下）。
- 鼓室（0.2mm のボクセル）: 鼓膜・耳小骨・前庭窓・蝸牛窓の凸包を 1.0mm 広げ、鼓膜より内側・側頭骨（BodyParts3D）の中・迷路の空所から 0.4mm 以上離れた所（前庭窓と蝸牛窓のまわりは除く）。耳小骨の所はくりぬく。約 450mm³。
- 外耳道: 鼓膜の外側から x の断面ごとに、側頭骨と外耳（耳介）の外の空いた所をたどる（前の中心から 5.5mm 以内）。壁の無い断面（骨と耳介の間のすき間）はそれまでの太さの円でつなぎ、耳介を外へ抜けたら終わり。断面ごとの中心と太さをならして段の無い管にする。鼓膜から約 20mm。
- 耳管の骨部: Z-Anatomy の耳管は軟骨部だけ（外側の端が鼓室から約 15mm 内側）なので、その端から鼓室まで、側頭骨の中で迷路から離れた最短の道に管（鼓室の口 1.4mm → 峡部 0.9mm → 軟骨部の太さ）を作る。終わりの 4mm は軟骨部の軸に沿って入る。
- 語: 平面図だけだった11語（外耳道・鼓室・半規管・前・後・外側半規管・膨大部稜・卵形嚢・球形嚢・前庭窓・蝸牛窓）と蝸牛の断面の3語（前庭階・蝸牛管・鼓室階）を3Dの語にし、骨迷路・膜迷路を足した。蝸牛＝前庭階＋蝸牛管＋鼓室階、前庭＝前庭（骨迷路の前庭の所）だけ、耳管＝軟骨部＋骨部。鼓室・外耳道は veil（ふだん薄く透かす）。中にある形（膜迷路・前庭窓・蝸牛窓・膨大部稜）は xray。
- 臓器の図「耳」: 色分けに外耳道・鼓室・骨迷路（前庭・半規管・前庭階・鼓室階で濃さを変える）・膜迷路（青）・前庭窓と蝸牛窓を足した。切り口に「水平断（前庭と外側半規管を通る面）」「蝸牛の軸を通る面」を足した。切り口に zoom（寄せる広さ）を書けるようにし、3Dのカメラは 3cm まで近づけるようにした（ダブルタップで寄るのは今までどおり 16cm まで）。
- GLB: 耳の部品は小さいので、形を減らすずれを 0.03mm にする（EAR_DETAIL）。形どうしが接するので AO の光をさえぎる形に入れない。sensory-za は 72KB → 362KB。
- 確かめ方: `python3 scripts/ear/ear.py --check` で data-raw/ear/check-<左右>-bony.png・membranous.png（外側・上・後ろから見た区分）・sections.png（x・y・z の断面）・middle-z.png・middle-y.png（鼓室と外耳道）。

## その3 眼の中・喉頭・鼻中隔と硬口蓋（2026-11-25）

scripts/eye/・scripts/larynx/・scripts/palate/（どれも export.mjs → <名前>.py）。BodyParts3D（と NasalSeg の CT）の形だけから作るので CC BY 4.0 のまま BodyParts3D の GLB に入れる。3つの parts.json は scripts/made/index.mjs がまとめて読み（部品ID は EY_…・LX_…・PL_…）、build-models の readElements に足す。

- 眼球の中（scripts/eye/eye.py）。眼の軸は眼球の中心（強膜の外接箱の中心）から角膜の中心への向き。
  - 瞳孔: 虹彩の点の軸からの距離のいちばん小さい値（約 1.5mm）を半径にした、虹彩のふちの厚さの間の黒い円板。穴なので強調したときだけ描く（tuck）。
  - 後眼房: 0.1mm のボクセルで、眼球の中のどの部品にも入らない空所のうち、毛様体小帯のいちばん後ろから虹彩のいちばん前までにあり、虹彩と水晶体（か小帯）の両方に接するかたまり（瞳孔の円柱と前眼房のまわりは除く）。約 34mm³。
  - 視神経円板・黄斑・中心窩: 網膜の内面（眼球の中心からの光線が最初に当たる面）に貼る板。接平面の上の (r, θ) を内面に映し、内面から硝子体の側へ高さの分だけ出す（裏は網膜の中へ 0.15mm 沈める）。視神経円板は視神経の、強膜の外 6mm までの点の中心の向き（横 1.6・縦 1.8mm の楕円。ふちが高く真ん中がくぼむ）。BodyParts3D の視神経は後ろの極の約 1.5mm 鼻側・2.3mm 上で入るので、中心窩は円板からではなく眼の軸の後ろの極から耳側へ 1.2mm・下へ 0.3mm に置く（見る軸は眼の軸より約5°耳側。円板との間は約 3.6mm）。黄斑は半径 1.3mm の円い板で、ふちから中へ高まってから中心窩へ落ちこむ。中心窩はそのくぼみの底の半径 0.55mm の板。黄斑の語は黄斑＋中心窩。
- 喉頭の中（scripts/larynx/larynx.py、0.2mm）。BodyParts3D には喉頭の内腔と粘膜の形が無い。
  - 内腔: 壁になる形（甲状軟骨・輪状軟骨・喉頭蓋・弾性円錐・声帯靱帯・声帯筋・甲状披裂筋・披裂軟骨・披裂筋・披裂喉頭蓋筋・正中輪状甲状靱帯など）を水平断ごとに 0.4mm 太らせ、壁の凸包の外とあわせて仕切りにし、正中（左右の声帯靱帯の内側の縁の真ん中）の種から塗り広げて、太らせた分を壁のきわまで戻す。声帯靱帯の高さ（yV）では左右の靱帯の間の約 1.5mm のすき間（声を出すときに近い形）だけが残り、その上で甲状披裂筋の内側まで広がる。
  - 粘膜: 内腔の外から 0.5mm。前庭ひだは yV の上 1.4〜5.4mm（いちばん高いのは 3.3mm）で、横の壁（いちばん近い外の点への向きが左右に近い所）から 2.3mm 盛り上げた粘膜（前後は声帯突起から前交連の手前まで）。声帯ひだは yV の下 2.6mm〜上 1.0mm の、前交連から声帯突起までの横の粘膜。
  - 空所: 声門裂は yV の ±0.5mm で yV の水平断のすき間の所、喉頭室は声門裂より上で真上 4mm 以内に前庭ひだがある所、声門下腔は声門裂より下で輪状軟骨の下縁まで（BodyParts3D の気管は輪状軟骨の中まで入るので、下の部分は気管の形と重なる）。
- 鼻中隔と硬口蓋（scripts/palate/palate.py、0.25mm）。
  - 鼻中隔: NasalSeg の左右の鼻腔の空気の間。左右に並ぶ列ごとに、右の空気のいちばん左と左の空気のいちばん右の間（7mm 以内。まわりを鼻中隔に囲まれた厚い所も入れる）。(y, z) の面でならし、正中から 2mm 以内の鋤骨・篩骨・鼻中隔軟骨も入れる。粘膜ごとの形なので veil（ふだん薄く透かし、中の骨と軟骨が見える）。
  - 硬口蓋: BodyParts3D の「上の歯肉」は口蓋の全体をおおう1つの形なので、歯列の内側（歯を (x, z) の面に映して囲み、いちばん後ろの大臼歯の間を後ろへのばした所）で歯から 3mm より離れた所を硬口蓋の粘膜にし、残りを歯肉として元の歯肉を置きかえる（scripts/made/index.mjs の REPLACES。元の形を書き出すときは NO_MADE=1）。どちらも元の歯肉の面へ吸い付ける。
- 語: 平面図だけだった12語（瞳孔・後眼房・黄斑・中心窩・視神経円板・声帯ひだ・声門・前庭ひだ・喉頭室・声門下腔・鼻中隔・硬口蓋）を3Dの語にし、声門裂を足した（声門＝声帯ひだ＋声門裂）。空所（声門裂・喉頭室・声門下腔）と鼻中隔は veil。
- 臓器の図: 眼に後眼房・黄斑・中心窩・視神経円板の色と切り口「眼底（眼球の後ろ半分を前から見る）」、喉頭に中のつくりの色と切り口「上から（喉頭鏡で見る向き）」、鼻に鼻中隔・硬口蓋の色（「鼻中隔を外して外側の壁を見る」で鼻中隔も外す）、咽頭に硬口蓋の色。
- 確かめ方: `python3 scripts/eye/eye.py --check`（data-raw/eye/check-<左右>-sections.png。後眼房は赤）、`python3 scripts/larynx/larynx.py --check`（data-raw/larynx/check-coronal.png・horizontal.png・sagittal.png）、`python3 scripts/palate/palate.py --check`（data-raw/palate/check-septum-coronal.png・check-septum-side.png・check-palate.png）。
