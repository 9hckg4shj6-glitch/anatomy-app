# 学びやすさ（計画と決まったこと）

## Context（なぜやるか）

2026-11-18 に「内容が膨大になり、3Dでうまく表せない用語まで入っていて、初心者から中級者まで使いづらい」という声があり、アプリ開発と解剖学の両方の目で数えて分析した（2,511語・302レッスン・問い方22種類）。

- **段差**: コースは「はじめての解剖 480語」と「全部 2,511語」の2つだけで、中級の段が無い。語の `level`（必修642・基礎945・発展924）はどの画面でも使っていなかった。
- **3Dで表せない語が混ざる**: 平面図だけの語 379、3Dの形が直径 15mm 未満で点にしか見えない語 56（脳幹の神経核・唾液核・上皮小体など）。レッスンの 39%（119）は、3Dではっきり見える語が半分に満たない。その多くは組織学（表皮の層・絨毛・腺房・赤脾髄）と発生学（原始心筒・中腸の回転）で、肉眼解剖の授業とは別の科目。
- **自作の模式の立体**（心臓の中・刺激伝導系・肺区域・胸膜・腎臓の中）が、本物の形と見分けられない。
- **説明が重い**: 説明は中央値158字、200字を超える語が727。
- **問い方が多い**: 初めから全部の問い方を学ぶ設定。

方針: 語は消さない（学んだ記録は語ID で残る）。**見せ方で棚に分け、段を作り、初めは軽く**。

## 決まったこと（2026-11-18）

- 案1〜5 を全部行う。まず案1と案3。
- 組織と発生学の内容は、ひとまず**臓器の図の中**で学ぶ（レッスンの道すじからは外す）。

## 案1 語を棚に分ける（立体の棚・図の棚）

- **図の棚の語**: 平面図の語（`plate`）と、3Dの形が小さすぎる語（`small`。直径 15mm 未満）。content/shelves.json（`npm run build:shelves`＝scripts/shelves.mjs が public/models/index.json と public/plates/index.json から作る。validate が古くないかを確かめる）。
- **図のレッスン**: 語の半分以上が図の棚の語のレッスン（src/content.ts の `isPlateUnit`）。今は65レッスン（細胞と組織11・皮膚4・発生4・血管の壁と胎児循環4・臓器の内部など）。
  - 学ぶのレッスンの一覧（道すじ）と「次のレッスン」・「このあと」には出さない（src/ui/lessons.ts の `pathUnits`）。系統の札の下に「平面図で覚える N レッスンは臓器の図の中で学びます」。
  - 臓器の図の画面の一番上に「図で学ぶレッスン」（src/course.ts の `organLessons`。5つ以上ならたたむ）。臓器の一覧に「図のレッスン 済み / 数」。
  - レッスンの入る臓器は `organOfLesson`（organs.json の units にあるか、初心者コースのレッスンは語の元のレッスンがいちばん多く入る臓器）。どの臓器にも入らない図のレッスンは validate が止める。そのため「胃と腸の細い動脈・直腸の静脈叢」を小腸と大腸に、「脳幹の神経核」を脳の底面と脳神経に入れた。
  - 図のレッスンの上の帯は「‹ 学ぶ ／ ○○の図」、終わりの画面は同じ臓器の次の図のレッスンと「○○の図へ」。
- 検索・演習の範囲・図鑑からは今までどおり全部のレッスンと語を選べる。

## 案3 3Dで無理な語の問い方

- 小さい語（`small`）には名前→位置（タップ）を出さない（study.ts の facetsFor。出ていた分は位置→名前に替える）。
- 小さい語のうち平面図に載っている語（`seePlate`、18語）は、問題とレッスンでその図を3Dの上に重ねて番号で示す（plateOfTerm が `plate ?? seePlate` を見る）。
- 模式の立体の語（`schematic: true`、46語: 心臓の中のつくり・刺激伝導系・心膜の層・線維輪、肺区域13、壁側胸膜と胸膜洞7、腎臓の中と被膜8）は、語のカードに「模式　3Dは位置と並びを示す模式の形で、実際の形とは違います。」。

## 案2 コースを3段にする

- はじめての解剖（初心者モード、480語）・**標準**（必修と基礎＝`level` 1・2、約1,590語）・すべての語（詳細モード、2,511語）。
- 標準のレッスンは詳細モードのレッスンから発展の語を除いたもの（同じレッスンID。語が残らないレッスンは出さない）。骨学試験と語根カードは標準でも使える。
- 骨格系の発展の語を標準に入れるかは決めていない（今は入れない。骨学試験は独立のまま全部の語で使える）。

## 案5 問い方は初めは3つ

- はじめて使う人の「学ぶ問い方」は 位置→名前・名前→位置・日本語→英語 の3つ。英語→日本語・筋の起始停止など・通るもの・向き・ホルモンは、コース「すべての語」を選んだときか、設定で足したとき。
- 今まで使っていた人（学んだ語がある人）は、今の問い方のまま（起動したときに今までの初めの値を保存する）。

## 案4 説明を2段にする

- 標準の語に「覚えること」（`point`、70字まで）を付ける（content/points.json。初心者コースの語は content/beginner.json の point）。
- 標準のコースの語のカードは、初心者と同じく「覚えること」を上に、今の説明は「くわしく」の中に。
