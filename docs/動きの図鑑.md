# 動きの図鑑（#/motions）

2026-11-21 の依頼「図鑑コーナに、あらゆるアニメーション項目を追加したい。呼吸時の肺周りの様子、肺循環と体循環に関する心臓の様子など、GitHub や Hugging Face など、たくさんのモデルがある場所から使えそうなモデルを探して実装」による。

## 入口

- 調べるタブの「3Dで調べる」に「動きの図鑑」（#/motions）。上の帯は「‹ 調べる ／ 動きの図鑑」。
- 臓器の図の心臓・血管・肺・肺区域・胸膜・縦隔・横隔膜と骨盤底の画面の頭に「動きで見る：▶ …」。

## 4つの動き

| ID | 名前 | 3Dで動かすもの | データ |
| --- | --- | --- | --- |
| breathing | 呼吸 | 肺（透かす）・気管と気管支・肋骨と肋軟骨と胸骨と胸椎・横隔膜・（心臓・肋間筋）。空気の粒（吸うと水色で下へ、吐くと灰色で上へ） | 4DMRI moving meshes |
| heartbeat | 心臓の拍動と心周期 | 4つの部屋の壁・弁・出入りする大血管。血液の粒（青＝静脈血・赤＝動脈血）は弁の流れの速さで進む。壁を透かす／前頭断 | ModularCirc |
| conduction | 刺激伝導系と心電図 | 上と同じ心臓（弁と腱索は隠す）＋刺激伝導系を光る色で。興奮の光が洞房結節→心房→房室結節→ヒス束→右脚・左脚→プルキンエ線維 | 時刻は模式（P 波・QRS と心周期に合わせた） |
| circulation | 肺循環と体循環 | 全身の主な血管（透かす）と心臓（拍動）・肺。粒は体循環の8つの道と肺循環の2つの道を回り、毛細血管で色が変わる。行き先は心拍出量の分かれ方の目安で選ぶ | 道すじは血管の形の中心線 |

画面は共通で、再生・止める・少し戻す／進める・速さ（¼・½・1倍）、今の区分の名前と説明、グラフ（押すとその時点で止まる）、見る向き、3Dのタップで名前（図鑑へ）、関係する語、出典。動きを減らす設定（prefers-reduced-motion）の端末では止めた状態で開く。

## 探した素材と選んだもの

- 呼吸: **4DMRI moving meshes**（Zenodo 7052607、CC BY 4.0）。2人の自由呼吸の 4DMRI（2.15 Hz）から取った左右の肺と胸郭の点の動き（MRI1 は 549 時点・48 呼吸）。ほかに TCIA の 4D-Lung（CT 画像だけ）、DIR-Lab などを見たが、形の動きがそのまま使えるのはこれだけ。
- 心臓: 4D の心臓の形の公開データは、病気の患者（肥大型心筋症）か CC BY-NC のもの、拡張末期だけの静的な形しか見つからなかった（Strocchi 2020 など）。Sketchfab の CC BY の拍動する心臓はログインしないと落とせない。そこで、形はアプリの心臓（BodyParts3D から作った模式の立体）のまま、動きの時間変化を **ModularCirc**（GitHub、Alan Turing Institute、MIT）の Korakianitis & Shi (2006) の4つの部屋のモデル（混合弾性の部屋・Bernoulli の弁・RLC の血管）で計算した。ModularCirc は Python 3.10 以上と numba を要るので、同じ式と値を scripts/motions/cardiac_cycle.py に書き直した。
  - 元の値のままだと心房の圧が 2mmHg ほどで、充満の7割が心房収縮（A 波）になる（ModularCirc のテストの期待値と同じ）。健康な成人に合わせ、心房の受動的な硬さだけ E_pas 0.5→0.3・k_pas 0.01→0.04 に変えた（心房収縮の分 約3割・左心室 141→53 mL・大動脈圧 122/81 mmHg・肺動脈圧 40/22 mmHg）。
- Hugging Face のデータセット・モデルも「heart」「cardiac」「lung」「4D」「mesh」で探したが、使える形の動きは無かった。

## データを作る（scripts/motions/）

1. `scripts/fetch-sources.sh` が 4DMRI moving meshes を data-raw/motions/ に置く。
2. `node scripts/motions/export.mjs` … public/models の GLB から、語の部品の頂点を体の座標で data-raw/motions/app.json に書く。
3. `python3 scripts/motions/breathing.py` → public/motions/breathing.json
   - MRI の向き（x 左・y 後ろ・z 上）をアプリの向き（x 左・y 上・z 前）に。肺の点の動きの主成分の1つめ（97%）を呼吸の信号にし、谷（呼気の終わり）で1呼吸ずつに切って 24 位相で平均。
   - 平均した変位を主成分2つ（99.9%）に分け、胸の箱の 2cm の格子に置く（MRI の肺の箱をアプリの肺の箱へ軸ごとに伸び縮み。点の無い所はラプラス方程式で広げ、縁は 0）。肺の場と胸郭の場を分ける（肺は胸壁の内側をすべるので）。横隔膜はドームの上ほど肺の場、縁ほど胸郭の場。
   - 1回換気量 約420 mL・1呼吸 約5.1秒（被験者の実測）。深呼吸は安静呼吸の 2.4 倍の動き・1.7 倍の周期の目安。
4. `python3 scripts/motions/cardiac_cycle.py` → public/motions/cardiac-cycle.json（1拍 1.0 秒を 200 点。4つの部屋の容積・圧、6つの流れ、活性化）
5. `python3 scripts/motions/paths.py` → public/motions/heart.json・circulation.json
   - 弁の輪の中心と向き（輪の点の主成分）、心尖（僧帽弁から一番遠い心室の壁の点）、刺激伝導系の道（右脚・左脚の前枝と後枝の中心線、プルキンエ線維の点 160 個を心尖から近い順）。
   - 血管の中心線: 頂点を 2.5mm の箱でならし、近い点のグラフで一番遠い2点を結ぶ最短の道を取り、道に垂直な薄い板に入る頂点の真ん中へ2回寄せる（最小全域木の道は管の面をぐるぐる回るので使わない）。部品の間のすき間はまとまりどうしを一番近い点で結ぶ。
   - 道すじは血管の語を流れの順に並べ、前の血管の次の血管の端に一番近い所で切ってつなぐ。動脈の終わりと静脈の始まりは毛細血管（短い波線）で結ぶ。

## 3Dでの動かし方（src/viewer.ts・src/motions.ts・src/ui/motions.ts）

- viewer の `setStage`（見せる部品だけを solid・glass・ghost・glow で。ほかは隠す）、`deformable` / `deformed` / `restoreDeform`（頂点を体の座標の Float32 に置き換えて動かす。行列は打ち消すので見た目は変わらない）、`setDots` / `dotsChanged`（粒。InstancedMesh）、`onTick`（毎フレーム）。画面を離れると全部元に戻す。
- 頂点の動きは状態に対して線形なので、点ごとに「形」を先に求め、毎フレームは重みを掛けて足すだけ（LinearDeform）。心臓は 9 の形（定数・左右の心室の縮み・左右の心房の縮み・4つの弁の開き）、呼吸は 4 の形（肺の場2つ・胸郭の場2つ）。
- 心臓の変位（heartDisplace）: 心室は心尖を通る長軸へ半径の 12% 縮み、心底が長さの 14% 心尖へ下がる。心房は心底の下がりで引き伸ばされ、心房の収縮で 10% 縮む。大血管は心底の近くだけ少し動く。弁は尖の先ほど開くと外へ・閉じると内へ。腱索は壁と一緒に動かす。
- 心周期の区分（cardiacTimeline）: 大動脈弁が開いていれば駆出期（左心室の圧が上がる間は急速、下がると緩徐）、僧帽弁が開いていれば充満期（心房が縮んでいれば心房収縮期、E 波が山の 3 割を下回ったら緩徐充満期）、両方閉じていれば直前に開いていた弁で等容性収縮期／等容性弛緩期。Ⅰ音＝僧帽弁が閉じる時、Ⅱ音＝大動脈弁が閉じる時。
